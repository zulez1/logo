# РЕШЕНО. Business Live — logo concepts

Built with the [logo-design skill](https://github.com/kaankiziltug/logo-design-skill).
Palette and type taken from the forum site: ink `#0D0F13`, amber `#F0B90B`; Unbounded 800 (wordmark), Montserrat 700 (BUSINESS LIVE). All text is outlined to paths.

| Concept | Idea | Files |
|---|---|---|
| **A — «РЕШЕНО.»** (recommended) | Wordmark ending in an amber diamond full stop: the decision is final. The diamond is the mark already used on the site. | `a-wordmark*.svg`, `a-lockup*.svg` |
| B — Ромб-галочка | The amber diamond with a negative-space check: problem solved. | `b-symbol*.svg`, `b-lockup*.svg` |
| C — Р-Live | Angular Р whose counter is a play/live triangle: Business Live. | `c-symbol*.svg`, `c-lockup*.svg` |

Files without `-color` are one-colour black. `concepts.png` is the overview sheet.
Regenerate: `python3 tools/build.py concepts` (needs fontTools and the Unbounded/Montserrat variable fonts; edit `FONTS` in `tools/outline.py`).
