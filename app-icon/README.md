# РЕШЕНО. Business Live — app icon

Based on the «Пьедестал» concept: the podium Ш with the winner's amber diamond.

- `app-icon-dark-1024.svg` / `app-icon-amber-1024.svg` — full-bleed masters for App Store / Google Play (the OS applies the rounded mask). `*-rounded.svg` are previews with corners.
- `png/` — 1024, 512, 180, 120 px of both versions.
- `web/` — favicon.ico + favicon.svg (16/32/48), apple-touch-icon (180), icon-192/512, maskable-512, `site.webmanifest`, `head-snippet.html` (paste into `<head>`).
- `preview.png` — the icon at real sizes on a home screen and in a browser tab.
